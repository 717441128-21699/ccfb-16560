# 老缫丝厂 · 挡车工一日

一个缫丝车间挡车工模拟游戏。玩家看管一排 40 绪缫丝机，把蚕茧上的丝抽出来并成 21 旦尼尔生丝。
核心手艺不是等茧自己出丝，而是**添绪**——盯住每根生丝的粗细，哪粒茧抽完了立刻补一粒新茧接上头，
否则生丝忽粗忽细、甚至断头。

技术栈：TypeScript + Canvas 2D + Web Worker（Vite 构建，Vitest 测试）。

## 玩法

游戏内一个班 8 小时（可在右上角调时辰倍速）。四个页面：

1. **缫丝车间**：一排 40 绪（2×20 布局）。每绪显示在缫茧数、当前纤度、丝道粗细、状态色。
   点击绪台添绪；绪台变红表示断头，点击接绪（接不好会留疙瘩）。左下角"一键添绪"统一补粒数不足的绪。
2. **煮茧**：6 口煮茧锅。装生茧 → 控温煮透 → 索绪（刷子找丝头）→ 理绪（剥外层乱丝），
   四步走完茧才进入熟茧库存。欠熟（煮熟度 < 0.82）索绪不动只出废丝；过熟（> 1.08）茧层溃散、废丝和断头增多。
3. **单绪监看**：任选一绪，看生丝纤度历史曲线（目标带 19.5~22.5D）、在缫各茧的剩余丝层、本绪出丝/断头/疙瘩/偏细时长。
   添绪不及时会在曲线上留下明显的"细腰"，断头处曲线断开。
4. **工钱结算**：实时预估与下班结算。工钱 = 计件工资（0.08 元/克）+ 匀度质量奖（按纤度 CV 评级 AAA/AA/A/B）
   − 断头扣罚（1.2 元/次）− 废丝扣罚（0.5 元/克）。

顶栏可调**车速**（0.8~2.2 m/s）：车速快产量高，但断头风险按车速 2.2 次方上升。

## 物理模型

### 茧丝纤度曲线（`src/engine/cocoon.ts`）

单粒茧丝的瞬时纤度按茧层位置 `x = 已抽丝长 / 总丝长 ∈ [0,1]` 计算，三项叠加，复刻公开测定的茧丝纤度曲线走势：

- **线性基线**：外层粗 → 内层细的整体趋势；
- **外层膨大峰**（高斯钟形，峰在茧层 12~15% 处）：对应测定曲线开头的小峰；
- **内层 sigmoid 陡降**：对应蛹衬前的加速变细。

最后乘一个数值迭代求出的标定系数，使全粒积分均值恰好等于设定的平均纤度（春茧 2.72D、夏秋茧 2.28D、晚秋茧 3.05D）。

**生丝纤度 = 当前在缫各粒茧瞬时纤度之和**。定粒 7~9 粒春茧并合落在 21D 目标带；
抽尽一粒不添绪，并合纤度立刻掉约 2.4D，曲线上可见缺口。

### 煮茧与索绪理绪

煮熟度 0~1.3，速率取决于水温和茧种温度效率（92℃ 标准水温约 7 游戏分钟煮透）。
索绪成功率随煮熟度变化，欠熟必败且产生废丝；理绪剥除外层乱丝，过熟茧剥掉更多。

### 断头与疙瘩

断头风险 = 车速主导项（基准 × 车速^2.2）+ 随机项 + 欠熟/过熟/蛹衬内层/粒数偏少附加项。
手工接绪有 18% 概率留下疙瘩，疙瘩期纤度虚高 28%。

### 三种茧（虚构参数，走势按公开测定标定）

| 茧种 | 丝长 | 平均纤度 | 定粒 | 煮熟区间 |
|---|---|---|---|---|
| 春茧（多丝量） | 1350 m | 2.72 D | 8 | 0.82~1.08 |
| 夏秋茧（中丝量） | 1050 m | 2.28 D | 9 | 0.85~1.06 |
| 晚秋茧（粗纤度） | 1200 m | 3.05 D | 7 | 0.80~1.10 |

## 架构

- `src/engine/`：纯 TypeScript 模拟引擎，与 DOM 无关，可在 Node 直接测试。
  - `cocoon.ts` 纤度曲线与茧种参数；`ReelingEngine.ts` 主引擎（煮茧、添绪、断头、Welford 在线 CV 统计、结算）；
  - `simWorker.ts` 把引擎跑在 Web Worker，快照 10Hz 节流回传；`SimClient.ts` 主线程封装。
- `src/ui/`：四个 Canvas 页面渲染器 + 命中区域交互。
- 所有逐 tick 计算（40 绪 × 每绪 7~9 粒茧）都在 Worker 内，主线程只负责渲染。

## 验证

```bash
npm install
npm test        # 15 个测试：纤度曲线走势、工艺规则、40 绪性能预算
npm run build   # 类型检查 + 生产构建
npm run dev     # 开发服务器
```

性能测试实测（60fps 单帧 tick + 快照，含预热）：**p50 ≈ 0.06ms，p95 ≈ 0.15ms，p99 ≈ 0.27ms**，远低于 5ms 预算。
纤度曲线测试断言三段走势（外层膨大峰、中段缓降、内层陡降至外层的 60% 以下）与积分均值吻合。
